# 02 - Karate y PetStore

Proyecto Maven de pruebas REST para la API pública PetStore. El escenario
encadena la creación, consulta, actualización, nueva consulta y eliminación de
un usuario con `username` único generado en cada ejecución.

- Pasos y versiones: [`readme.txt`](readme.txt)
- Resultados observados: [`conclusiones.txt`](conclusiones.txt)
- Reporte HTML: [`reporte/karate-summary.html`](reporte/karate-summary.html)

Ejecuta `mvn clean test` desde esta carpeta. El reporte completo también se
genera en `target/karate-reports/`.
